# สั่งการ คลีน — ระบบจัดทำสัญญาบริการทำความสะอาด

เว็บแอปสำหรับบริษัท **สั่งการ คลีน จำกัด** ใช้กรอกข้อมูลลูกค้าแล้วสร้างสัญญาจ้างทำความสะอาดพร้อมเอกสารแนบท้ายสัญญา 1 จากนั้นพิมพ์หรือบันทึกเป็น PDF ได้ทันที

## ใช้ทำอะไรได้

- กรอกข้อมูลผู้ว่าจ้าง ระยะเวลา จำนวนพนักงานหลายตำแหน่ง และอัตราค่าจ้าง
- คำนวณค่าบริการรายเดือน / ทั้งสัญญา และตัวหนังสือภาษาไทยให้อัตโนมัติ
- สลับเงื่อนไขข้อ 6 ว่ารวมหรือไม่รวมค่าอุปกรณ์น้ำยา
- แยกถุงขยะ/กระดาษชำระ ใส่ขนาด-จำนวนได้ (ถุงขยะหลายขนาดในสัญญาเดียว)
- บันทึกสัญญาไว้ในคลัง เปิดดูและแก้ไขได้ตลอดในเบราว์เซอร์
- อัปโหลดเอกสารที่เกี่ยวข้องแนบกับสัญญาที่บันทึกแล้ว
- ดูตัวอย่างสัญญาสดบนหน้าจอ แล้วพิมพ์หรือ Save as PDF ขนาด A4 (3 หน้า)
- ร่างล่าสุดถูกบันทึกในเบราว์เซอร์อัตโนมัติ
- เลขที่สัญญาแบบ `SC-ปีพ.ศ.-เดือน-ลำดับ` เช่น `SC-2569-09-001`

ผู้รับจ้างในเอกสารคือบริษัท สั่งการ คลีน จำกัด (เลขทะเบียนนิติบุคคล 0105569168329)

## วิธีรัน

ต้องมี Node.js 18 ขึ้นไป

```bash
npm install
npm run dev -- --port 43123
```

เปิดเบราว์เซอร์ที่ [http://localhost:43123](http://localhost:43123)

## GitHub Pages

เว็บไซต์สาธารณะอยู่ที่:

**https://pattarish-web.github.io/SKC-Contact/**

อัปเดตหน้าเว็บด้วยคำสั่ง:

```bash
npm run deploy:pages
```

สร้างไฟล์พร้อมใช้งานสำหรับขึ้นเซิร์ฟเวอร์:

```bash
npm run build
npm start -- --port 43123
```

## การพิมพ์สัญญา

1. กรอกข้อมูลให้ครบ (หรือกด **ตัวอย่าง** เพื่อลอง)
2. กด **พิมพ์ / บันทึก PDF**
3. ในหน้าต่างพิมพ์ เลือกเครื่องพิมพ์เป็น **Save as PDF** หรือ **Microsoft Print to PDF**
4. ตั้งค่ากระดาษเป็น A4 แนวตั้ง และเปิด “Background graphics” หากตัวอักษรหัวข้อจางเกินไป

## หมายเหตุ

- ราคาสัญญาไม่รวมภาษีมูลค่าเพิ่ม ตามข้อความในสัญญา ข้อ 5 และหมายเหตุแนบท้าย
- วันที่ในสัญญาแสดงเป็น พ.ศ. เช่น 7 กันยายน 2569
- กด **บันทึกสัญญา** แล้วรายการจะเก็บในเครื่อง และพยายามซิงก์คลังร่วม
- **วิธีที่เสถียรที่สุดข้ามเครื่อง:** ในคลังกด **เลือกโฟลเดอร์ร่วม** (Chrome/Edge) แล้วเลือกโฟลเดอร์ OneDrive / Google Drive / ไดรฟ์บริษัท ที่ทั้งสองเครื่องใช้ร่วมกัน
- ระบบไม่ทับคลังที่มีข้อมูลด้วยคลังว่าง และเก็บสำเนาสำรองในเครื่องอัตโนมัติ
- ส่งออก / นำเข้าไฟล์ใช้สำรองเพิ่มได้
- ร่างที่กำลังแก้ถูกบันทึกอัตโนมัติใน localStorage ของเครื่องที่เปิดใช้งาน
